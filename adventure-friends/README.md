# Aster 社区好友库

新配置请提交到 [online-config/adventure-friends/](../online-config/adventure-friends/)。此目录供旧版客户端读取。

开启「社交版拓展内容」，在地图的「用户」页点「导出玩家数据」。将导出的 `玩家名.json` 提交到本目录。以后更新资料时，替换同一玩家的旧文件，并保留 JSON 内的 `playerId`。从旧文件名迁移时，删除原来的 `player-<公开编号>.json`。

A327 起可以读取以玩家名命名的文件，也兼容旧文件名。A326 及更早的版本需要升级才能同步改名后的文件。

文件包含昵称、头像、最多三株出借植物与阶数，以及常规通关留下的各关各星级最佳记录。阵型可预览的关卡会附上棋盘和选卡，已记录的战术黄瓜次数也会保留。游戏生成独立的公开编号。导出的 JSON 可以在上传前打开检查。

A354 起，导出文件的 `totalStars` 记录玩家在各世界获得的总星数。旧文件缺少该字段时，好友列表上的星星图标旁显示 0。

同一安装中的每个玩家存档有自己的公开编号。社区成绩来自玩家投稿，供离线好友和阵型参考。

游戏在打开「用户」、关卡成绩、友情阳光或借用植物时检查 GitHub 好友库。下载在后台进行，更新后的资料会在下次打开相关界面时显示。离线时仍可读取上次成功获取的好友资料和随包提供的示例好友。
