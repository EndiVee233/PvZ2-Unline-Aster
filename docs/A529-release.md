# PvZ2-Unline:Aster A529 正式热修复

- 修复 A525 ARM64 启动报错。桥接器将游戏引擎的地址预留从 32 MiB 扩大到 48 MiB，保留引擎和其余库的加载地址。
- 修复秦陵动画引用清理中的错误，涉及黏弹糯米、僵尸豆荚、电力绿茶等触发动画效果时的闪退。
- 修复游戏公告偶尔显示错误背景的问题。
- 修复刺客丢下卷轴后走路时刀消失，以及向右走时断手动画和朝向异常的问题。
- 秦俑僵尸被战术黄瓜击败时直接倒地。

两个 APK 均内置完整资源，可覆盖安装。ARM32 沿用已在 WSA 验收的 A528 游戏引擎和资源。ARM64 覆盖安装后已在 WSA 启动至标题页，原反馈的 Android 14 手机尚未复测。**不推荐 ARM64，优先使用 ARM32。**
