# PvZ2-Unline:Aster A462 预发布

**不推荐 ARM64，优先使用 ARM32。** 两个 APK 都包含完整安装资源。ARM32 的秦陵玩法和僵尸豆荚已分项在 WSA 验收。ARM64 只完成打包、签名和共享资源校验，实机性能和设备兼容性仍待确认。

从星系地图的失落之城附近进入「秦始皇陵」。第 1 天提供一关示例，可体验弯曲坑道、草垛、秦陵小推车和第一部分的原生战斗音乐。世界地图美术仍在制作，后续关卡目前为占位。地宫之主与秦陵第二部分暂未开放。

- 示例关包含秦陵基础僵尸、旗手、巨人和小鬼，以及骑兵、小贩与小猪、弓箭手、醉汉、盾卫、刺客、方士和兵马俑。可在僵尸图鉴查看已接入的秦陵条目。
- 接入草垛、魔藤、电力绿茶和僵尸豆荚。僵尸豆荚的 1–4 阶采用 Aster 的召唤配置。四阶在战斗中种下时有 50% 概率通过原生机制开大，触发时播放光效并召唤巨人豆腐僵尸。
- 机枪豆腐僵尸向右连射，胡萝卜帽和西瓜帽跟随头盔动画。示例关恢复常规卡片阶数和秦陵僵尸波次。
