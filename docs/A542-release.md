# PvZ2-Unline:Aster A542 正式版

相比 A529

- 秦始皇陵地图改用狂野西部的路网，保留秦陵星空背景。加入支线门、开门动画和临时钥匙图标，调整关卡点、道路接缝和路沿层级，通关后草坪随滚草铺开。
- 拾取秦陵钱袋时播放秦陵原曲，修复两段音乐重叠的问题。小猪被炸死或电死时播放自己的死亡动画。
- 修复好友页「好友」和「添加好友」选中标签与尖角之间的黑线。
- 修复冒险通关成绩漏记，包括碎片奖励关卡首通进入奖励过场时的保存逻辑。碎片首通修复已做逻辑检查。
- 修复「邪恶入侵」「巨人危机」「暴走雪人」的剩余次数显示为 −1 的问题。三个模式按设备当地日期各刷新 1 次，旧存档中的负数会自动修复。
- 修复「社交版拓展内容」打开错误设置页面的问题。黏弹糯米和电力绿茶会跳过正在化灰或显示电击骨骼的僵尸。

两个 APK 均内置完整资源，可覆盖安装。ARM32 已在 WSA 分项验收。ARM64 已校验签名、共享资源和引擎加载地址，尚未实机验收。**不推荐 ARM64，优先使用 ARM32。**
