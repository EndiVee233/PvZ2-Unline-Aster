# PvZ2-Unline:Aster A350 正式版

**不推荐 ARM64，优先使用 ARM32。** A350 ARM32 已在 WSA 验收世界地图顶栏的对齐和点击。两份 APK 均包含完整资源。A350 ARM64 已通过打包、签名和共享引擎校验，仍待设备验收。

- 世界地图的「用户」和「签到」重新对齐，「好友」等比例放大。「用户」按下时亮起暖黄色描边，尺寸和位置保持一致。
- 植物进阶页的技能标签改为左对齐，为「进阶」按钮留出空间。PVP 的立即完成按钮改为直接显示所需钻石数量。
- 修复社交拓展开启后，部分支线传送带关卡跳过关卡菜单的问题。
- 修复拾取好友借用植物后，跟随指针的种植预览异常。
- 锁定高视角并移除视角切换设置。修正 PVP 掠夺弹窗中邪恶戴夫头像的位置。
- 修复打开潘妮宝物时，资源组在读取完成前释放导致的闪退。
