# Aster 在线配置

A509 起从这里读取在线配置。后续更新请编辑此目录下的文件。PvP 和好友在线同步需要 A509 或更新版本。

| 路径 | 用途 |
| --- | --- |
| [announcement.txt](announcement.txt) | 标题页的游戏更新公告 |
| [pvp-presets/](pvp-presets/) | PvP 共享阵容、阳光上限和特殊敌人 |
| [adventure-friends/](adventure-friends/) | 玩家主动投稿的公开好友档案 |

公告使用 UTF-8 纯文本。第一行填写 GitHub 上要公告的版本，例如 `A509`。第二行起填写正文，可以换行。正文最多 1024 个字符。版本一致时每个安装版本只显示一次正文。版本不一致时，每次冷启动最多提醒一次，同一安装版本累计最多提醒三次。换版本后从零开始计数。

请在相应安装包可下载后更新第一行和正文。PvP 和好友资料沿用客户端已有的联网选项和本地缓存。公告下载失败会直接进入游戏。
