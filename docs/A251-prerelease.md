# PvZ2-Unline:Aster A251 预发布

优先使用 ARM32。ARM64 未经实机验收，不推荐使用。

- 腾讯社交玩法移植先开放埃及第 1、2 天的战斗计时。个人最佳按玩家、关卡和星级保存。有效通关时会记录用时与场上阵型，包括植物类型、格位、阶数和挂件。游戏内查看成绩和阵型、星级自选及离线好友榜仍在移植中。
- 自 A236 起，本包也包含签到、天空之城地图背景铺满、「一炮当关」正常发射与宽屏命中、僵尸入场淡入，以及外部关卡文件读取方面的改动。

ARM32 已在 WSA 验证计时、暂停与重试，以及有效通关的成绩和阵型写入。两份发布 APK 均包含完整资源，签名、对齐和包内文件校验已通过。完整包的全新安装仍待验收。

构建脚本使用已包含上述修复的 A250 ARM32、ARM64 APK 作为底包。默认输出两份完整 APK。WSA 开发用裁剪包和清场工具由单独参数构建。
