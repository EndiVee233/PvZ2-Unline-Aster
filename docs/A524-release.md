# PvZ2-Unline:Aster A524 正式版

**不推荐 ARM64，优先使用 ARM32。** 两个安装包均内置完整资源，可覆盖安装。ARM32 已在 WSA 复测弓箭手断手和幽灵辣椒图鉴。ARM64 已校验打包与签名，尚未实机验收。

本次更新以 A512 正式版为基线。 [A512 发布说明](https://github.com/EndiVee233/PvZ2-Unline-Aster/releases/tag/A512)

- 秦陵弓箭手断手后停止射箭并恢复向前走。正在准备的箭也会取消。
- 幽灵辣椒归入秦始皇陵，图鉴使用秦陵背景。
- 调整黏弹糯米的弹体飞行逻辑，处理部分 ARM32 设备上攻击时卡死的反馈。
- 修正秦陵僵尸与原有 PvP 僵尸的类型编号冲突。
- 秦陵战斗与地图资源改用独立世界资源包，沿用其他世界的加载流程。启动时保留已校验的僵尸资源，减少重复解包。
- 新增报错页面。遇到可捕获的启动错误或崩溃时，可以复制诊断信息并重启游戏。
