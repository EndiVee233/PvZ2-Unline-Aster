# PvZ2-Unline:Aster A512 正式版

**不推荐 ARM64，优先使用 ARM32。** 两个 APK 都内置完整资源，可以覆盖安装。ARM32 的新增玩法与重点修复已分项在 WSA 验证。ARM64 使用同一游戏引擎和资源，已校验打包与签名，仍待设备验收。

本次更新以秦始皇陵预发布版 A462 为基线。 [A462 发布说明](https://github.com/EndiVee233/PvZ2-Unline-Aster/releases/tag/A462)

## 秦始皇陵第一部分

- 新增糯米投手（黏弹糯米）和阳光韭菜。糯米普攻优先锁定本行最右侧的有效目标，命中后把糯米粘到僵尸脚下，最多叠三层。爆炸后清空层数，炸死的僵尸按普通灰烬效果化灰。
- 接入秦陵六株植物的图鉴、植物进阶和装扮预览，调整卡片贴图、锁定状态和碎片显示。草垛和魔藤目前只开放一阶。
- 修复电力绿茶大招被普攻打断、误伤友方豆腐僵尸，以及僵尸豆荚在矿车上移动时重置生长进度、重复召唤的问题。修正阳光韭菜生长和收割动画。
- 调整坑道、地砖、草垛、植物与僵尸的绘制层次。修复草垛大招放错位置、陶俑将军与友方僵尸交战、醉汉换行时卡在两行之间的问题。刺客断手后会掉刀，之后只能啃食。
- 秦陵提供三关坑道示例。关卡作者可以沿用黑暗时代「剧院惊魂」的逐格格式，用 `TowerDefendProperties.Roads` 定义坑道。秦陵后续剧情关、地宫之主和第二部分暂未开放。

## 冒险、签到与 PvP

- 完成星级挑战时，通关时间更快会一并刷新无星纪录。某颗星的任一条件失败后，会取消仅属于该星的限制，其他仍可获得的星继续计数。修复零星结算的标题和亮星显示，以及碎片奖励关卡的僵尸阶数偏高。
- 关卡名移到右侧星星上方，保留原字体并改用浅金色和深棕描边。左栏标题只显示「好友成绩」。
- 修复植物探险次数用完后次日未回满，以及 11 月第 27 格装扮碎片无法签到或补签。签到绿框指向最早未领的一格，补齐后停在当天。
- PvP 兑换商店可离线保存兑换结果，奖池加入僵尸豆荚碎片，500 奖牌兑换 5 片。

## 设置与更新公告

- 设置新增「僵尸场外加速」，默认开启，重启后保留选择。
- 恢复初版「游戏公告」弹窗。版本一致时，每个安装版本只显示一次公告。版本不一致时，冷启动累计最多提醒三次，更换安装版本后重新计数。
- 公告、PvP 共享阵容和好友资料统一由 `online-config/` 提供。旧版本需要升级才能使用在线同步。 [在线配置目录](https://github.com/EndiVee233/PvZ2-Unline-Aster/tree/main/online-config)
